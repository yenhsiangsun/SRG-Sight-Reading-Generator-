# 起句差異與呼應 B87

人類回饋：生成的開頭相似，聽不出足夠變化。此批只調整目前一般練習使用的 musical-intent 旋律路徑，保留原有專項、混合拍號、變音與 legacy 路徑，以及 B86 雙聲部和聲修正。

## 問題依據

以固定 C 調、六種設定各 24 個開發種子抽樣：原版所有樣本都從 MIDI 72 的主音開始，第一個不同音都向上。現有動機皆以零為起點，而正向樂句弧線與固定的中心音域又削弱了不同動機的方向差異。節奏入口也只使用少數排列。這是此批樣本的觀察，不能推論所有音域／調性都固定在 C5。

## 修改

- 每種樂句語法由三個動機擴充至八個，包含上行、下行、回轉、同音呼應、跳進後回應等。起音可選目前音階中實際存在的主音、三音或五音，另選可容納整個手勢的音域位置。
- 第一批實際音符呈現短動機；回應句反向呼應，回歸句記得原動機。既有樂句、和聲路線與鄰音式終止仍保留。修改正向弧線的偏向，避免下行動機又全部被推回上行。
- 中、複雜節奏重排同長度拍群及其內部時值，不改該拍群的時值庫存。發展句仍保留活動增長；不以減少細分把複雜節奏變簡單。簡單節奏可在可讀的位置合併長音。
- 少量短暫延後的旋律入口保留原小節拍數；伴奏仍可先建立強拍。休止符短、總量受限，後面必須有實音，不能形成連續空缺。
- 新的選擇重用原本動機抽樣的熵，不增加全域亂數抽取，不依賴真人歷史或任何儲存資料。節奏選擇不讀音高難度。新欄位 `musicalIntent.opening` 可省略，舊譜仍可驗證並保持原樣。
- 三連音移動到其他拍位時，用既有整數 tick 累加時值，避免浮點數誤差造成看似越過拍界的起點。

## 驗證與聽感界線

開發種子 `87001–87024`，另保留新種子 `87101–87124`。六個設定為鋼琴大調 4/4 適中、揚琴大調 4/4 複雜、鋼琴自然小調 6/8 適中、笙大調 4/4 簡單、琵琶五聲 6/8 複雜、二胡多利安 3/4 適中。每個設定保留修改前後完整輸出；共 288 組對照，包含 144 組新的保留種子對照。

檢查實際生成的起音、前八個音相對輪廓、第一個移動方向、兩小節節奏，以及音域、音階、小節時值與雙聲部規則。另以測試驗證不同音高難度不影響節奏，三種節奏難度仍分明，長句發展與終止可保留，舊的四組人工選定路徑不受此批入口影響。

獨立試聽頁以開發集合預先固定的四組設定／種子製作，並跑到目前 App 的速度修飾、雙聲部協調、和弦與演奏記號階段。鋼琴例一 `87001`、例二 `87002` 使用相同設定，另外是揚琴 `87003`、鋼琴小調 `87004`。音檔離線合成後只調整整體音量，保持兩聲部的相對音量；不自動播放，不宣稱人工試聽通過。

變化多不等於已經好聽。窄音域可能無法容納整個動機，此時既有合法路徑優先；同一首內有意識的重複與呼應也不應全部消除。新舊版本都保留在快照，可依人工試聽回饋有限調整。沒有 push、上傳、CI、原生同步、TestFlight 或送審動作。
