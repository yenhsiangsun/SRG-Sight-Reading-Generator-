# 樂譜 PDF 匯出

練習頁「收藏這份譜」旁的「匯出 PDF」會下載當前樂譜，不重新隨機出題。測驗模式使用畫面上相同的單音版本；測驗進行中停用匯出。

- A4 直式；每頁保留樂器名稱、題號、拍號／譜表資訊，以及畫面目前的速度。
- 混合四分拍與八分拍時，列出等值速度，例如 `♩ = 76 · ♪ = 152`。
- 使用與畫面共用的 VexFlow 排版器，保留和聲、換譜號、三連音、演奏記號、8va／8vb；PDF 不包含游標、按鈕或小精靈。
- 依完整譜行分頁，大譜表雙手不拆開。兩小節過密時改用每行一小節。
- 排版輸出為高解析度 Canvas 圖像嵌入 PDF，並非可編輯向量譜。逐頁製作，避免建立整首樂譜高度的巨大 Canvas。
- jsPDF 按需載入；PDF 在裝置端製作，不需上傳樂譜。下載位置由瀏覽器決定。

驗證包含單譜表、16 小節／4 頁大譜表、混合拍號、繁體中文、和聲與演奏記號；下載後以 Poppler 逐頁渲染確認。自動測試檢查完整譜行分頁、A4 邊界、Canvas 大小限制與速度換算。iPad 原生 App 的檔案分享需待原生封裝整合時另行驗證。
