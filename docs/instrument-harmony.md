# 樂器和聲與琵琶換譜號

2026-09-16：新譜在原有音高／節奏生成後加入少量和聲，不改原旋律、休止時間或拍數。所有新增音均在自訂音域、當次隨機調式之內；沒有合適組合時保留單音。

- 鋼琴大譜表：只在左手加入雙音或三音，檢查與同時右手旋律的協和關係；低於 C3 的低音採較開放的五度／八度，不堆疊密集三度。初級手掌跨度最多五度，中高級最多八度。
- 琵琶：偶爾加入大小三度、完全四／五度、大小六度雙音。採標準 A2–D3–E3–A3 定弦，保守使用相鄰兩弦與相差不超過四個半音的按弦位置；空弦另計。這是練習用的保守子集，不涵蓋全部琵琶技巧或非標準定弦。
- 混合譜表：在步驟二直接選「混合譜表（高音＋低音・單行）」，琵琶預設此項。依實際音域在同一行切換兩種譜號；同時規劃譜號與八度線，音高允許時最多保留兩條加線。優先在拍組邊界換譜號；組內遇到大幅跳躍才換譜號並拆開連桿。換行重印當時譜號，必要時在上行末附提示譜號。固定高／低音譜表可另選，大譜表仍為上下兩行。
- 笙類：高音鍵笙、中音笙、次中音笙、低音笙均支援少量和聲。初階雙音，中階雙音／三音，進階另可少量四音；每個組合均通過對應型制檢查。高音鍵笙使用下列 36 簧音位；其他三種使用另一套按鈕式排笙／抱笙配置，不將高音笙的指法移調套用。

和聲上限按有聲事件數計算：琵琶初／中／高級約 10%／16%／20%，笙初／中級約 10%／16%，每小節最多一次；鋼琴左手約 22%／28%／32%，每小節最多兩次。進階笙的偶發連續段另依下述規則。短促的十六分音符及沒有安全組合的位置不加和聲，因此實際比例可能更低。

## 鋼琴與揚琴的旋律／伴奏協調（2026-10-19）

目前只有鋼琴與揚琴選擇大譜表時會生成真正同時演奏的兩個聲部；其他樂器的大譜表是單旋律跨譜表。新譜保留原本的主旋律規劃，在音階／跳進專項及快速音群修正後，以完成的主旋律、共同和聲計畫與樂句重新安排低音。此階段不更改主旋律或消耗全域隨機流；既有收藏不重新生成伴奏。

- 簡單節奏採兩拍長音或複拍子大拍；適中增加四分／八分音符；複雜加入少量十六分音符。伴奏不另加三連音或三十二分音符與主旋律競爭。6/8、9/8、12/8 依附點四分音符大拍安排，7/8 保留 2+2+3，簡單 5/4 為二分、四分、二分，呈現 3+2。
- 低音以當小節和弦的根音、和弦音與數種反覆分解手勢為材料，保留鄰近聲部連接與反向移動的偏好。反覆伴奏不再被當作主旋律缺乏變化而扣分；音域及各級音程上限仍須通過原有驗證。
- 逐一檢查低音持續期間的所有旋律音，包括低音起音後才出現的重拍。對未解決的二度、七度與三全音提高成本，保留能以級進準備／解決的經過音、鄰音與延留音；這是調式伴奏策略，並非完整嚴格對位求解。
- 收尾低音在音域內可行時落調式主音，配合主旋律終止。音階專項保留低音級進與鄰音收尾。窄音域沒有主音時使用合法材料，不強塞越界音；非調性題目不套調性伴奏，啟用變化音的調性題目則保留上聲部變化音。
- 鋼琴額外雙音／三音只放在自然拍點，且所有新增和弦音都檢查整個延音期間的旋律。沒有合適配置時保留單音支撐；揚琴沿用兩條單音聲部，未新增密集和弦。

生成管線在 `composeExercise` 的專項塑形後與 `useExercise` 的快速音群修正後，均經過同一個 `coordinateGrandStaff`。樂理參考：[Music Theory for the 21st-Century Classroom：非和弦音](https://musictheory.pugetsound.edu/mt21c/NonChordTonesIntroduction.html)及[伴奏織體](https://musictheory.pugetsound.edu/mt21c/AccompanimentalTexture.html)。

### 進階笙的連續和聲（2026-09-28）

四種笙在音高進階時約 55% 嘗試安排一段 2–3 次連續和聲，每次只有 2–3 音。8 小節至多一段；16 小節以上可偶爾有兩段，並相隔至少三小節。和聲事件總數不超過有聲事件的 30%；原有孤立和弦仍可極少量出現四音。

段首位於自然拍組起點，段內可用調式音向前連接，優先考慮當小節和聲中心，並以整段按鍵移動成本選取配置。所有和弦沿用相同指法、音域與低音疏距限制；低音笙只選至少四分音符長度，其他笙至少八分音符。休止會中斷段落，單旋律大譜表換譜表不會被當作休止。最後三個旋律音不插入連續段，保留原有收尾。初中階抽選流程及比例不變。

## 笙的實體按鍵規則

依使用者提供的「三十六簧加鍵方笙指法音位圖（g–♯f³）、1=C」逐鍵轉錄。以下各列均按圖片由左往右的實體位置排列，採 C4 = MIDI 60。

| 手指 | 按鍵音高（由左至右） |
| --- | --- |
| 左小指 | F6 |
| 左中指 | B5、F♯5、C5、F4 |
| 左無名指 | B3 |
| 右無名指 | C4 |
| 右中指 | F♯4、B4、F5、C6 |
| 右小指 | F♯6 |
| 左食指 | D♯6、A5、E5、A♯4、D♯4、A3 |
| 右食指 | A♯3、E4、A4、D♯5、A♯5、E6 |
| 左拇指 | C♯6、G5、D5、G♯4、C♯4、G3 |
| 右拇指 | G♯3、D4、G4、C♯5、G♯5、D6 |

一根手指預設控制一鍵，最多同時按兩個相鄰鍵。三個相鄰鍵的罕見指法暫不生成。例：G♯3＋G4 同屬右拇指，隔著 D4，必須拒絕。G♯3＋D4 雖符合按鍵鄰接規則，仍須通過獨立的音樂和聲檢查才可能出題。

### 中音、次中音與低音笙（2026-09-23）

採用作曲家／演奏者[王辰威的排笙／抱笙技法說明及圖 2](https://wangchenwei.wordpress.com/essays/diyinsheng/)。來源說明此類中音、次中音與低音笙共用音位原理：左手各八度由左至右為 C、D、E、F♯、G♯、A♯；右手由左至右為 B、A、G、F、E♭、D♭。垂直方向為相同音的不同八度，手指可移動，並非高音鍵笙的固定手指分配。程式保留絕對音名的左右手分工，不依最低音任意平移指法。

| 樂器 | 本 APP 採用的實音音域 | 音位模型 |
| --- | --- | --- |
| 高音鍵笙 | G3–F♯6 | 使用者提供的 36 簧固定指法圖 |
| 中音笙 | C3–B5 | 全音分手按鈕式配置 |
| 次中音笙 | G2–F♯5 | 全音分手按鈕式配置 |
| 低音笙 | C2–G4 | 全音分手按鈕式配置 |

**以下是 APP 選取的保守練習限制，並非來源公布的精確手掌跨度，也不是所有琴型的完整可奏和弦表：**

- 中低音笙同一手最多同時按兩鍵、各用一根手指；兩鍵最多相隔兩個橫向鍵位、最多跨相鄰兩個八度列。不預設連動鍵、一指多鍵或特殊伸展。
- 低於 C3 時最多雙音，低音與相鄰音至少相隔七個半音；採五度／八度等較開放的配置，避免密集低音。
- 和声音仍須符合當次調式、自訂音域及既有協和音程條件，整個和弦跨度最多八度；沒有合適組合便保留單音。
- 孤立和聲與連續段首放在自然拍組起點：6/8 是兩個附點四分音符拍點，7/8 跟隨當小節拍組。低音笙只加在至少四分音符長度的音上；孤立四音和弦也需至少四分音符長度。初中階每小節最多一次，進階另可出現上述短段。
- 自訂音域可繼續產生原旋律，但超出已知型制音域的音不添加和聲。未識別型制不借用高音笙規則。

這些限制以按鈕式排笙／抱笙為預設，**不涵蓋鋼琴黑白鍵式鍵盤笙、傳統笙、其他廠牌特殊音位或所有跨和弦換指技巧**。不同實琴仍須核對音位及觸鍵距離。此處是可擴充的型制規則與保守生成策略，不宣稱保證每個型號、每位演奏者都能演奏所有生成內容。

## 顯示、播放與測驗

`GeneratedNote.chord` 儲存完整的同時發聲音高，包含原本旋律或低音；同一事件只佔一次時值。VexFlow 每個音都有符頭及必要臨時記號；播放逐音同時排程，換譜號或 8va/8vb 不改 MIDI。

收音評分仍為單音：琵琶／所有笙類切到測驗模式時，顯示並評分原旋律；切回自由練習恢復和聲。鋼琴獨立雙手收音評分尚未支援。收藏儲存完整和聲，重新開啟時依各笙的型制檢查和弦音域及按鍵配置；舊單音收藏可繼續開啟，不自動改寫。
