# 樂器和聲與琵琶換譜號

2026-09-16：新譜在原有音高／節奏生成後加入少量和聲，不改原旋律、休止時間或拍數。所有新增音均在自訂音域、當次隨機調式之內；沒有合適組合時保留單音。

- 鋼琴大譜表：只在左手加入雙音或三音，檢查與同時右手旋律的協和關係；低於 C3 的低音採較開放的五度／八度，不堆疊密集三度。初級手掌跨度最多五度，中高級最多八度。
- 琵琶：偶爾加入大小三度、完全四／五度、大小六度雙音。採標準 A2–D3–E3–A3 定弦，保守使用相鄰兩弦與相差不超過四個半音的按弦位置；空弦另計。這是練習用的保守子集，不涵蓋全部琵琶技巧或非標準定弦。
- 混合譜表：在步驟二直接選「混合譜表（高音＋低音・單行）」，琵琶預設此項。依實際音域在同一行切換兩種譜號；同時規劃譜號與八度線，音高允許時最多保留兩條加線。優先在拍組邊界換譜號；組內遇到大幅跳躍才換譜號並拆開連桿。換行重印當時譜號，必要時在上行末附提示譜號。固定高／低音譜表可另選，大譜表仍為上下兩行。
- 高音鍵笙：雙音／三音為主，進階少量四音。每次加入前均檢查下列 36 簧音位；不套用到次中音笙、低音笙或傳統笙。

和聲上限按有聲事件數計算：琵琶與笙初／中／高級約 10%／16%／20%，每小節最多一次；鋼琴左手約 22%／28%／32%，每小節最多兩次。短促的十六分音符、連續相鄰事件及沒有安全組合的位置不加和聲，因此實際比例可能更低。

## 笙的實體按鍵規則

依使用者提供的「三十六簧加鍵方笙指法音位圖（g–♯f³）、1=C」逐鍵轉錄。以下各列均按圖片由左往右的實體位置排列，採 C4 = MIDI 60。

| 手指 | 按鍵音高（由左至右） |
| --- | --- |
| 左小指 | F6 |
| 左中指 | B5、F♯5、C5、F4 |
| 左無名指 | B3 |
| 右無名指 | C4 |
| 右中指 | F♯4、B4、F5、C6 |
| 右小指 | F♯6 |
| 左食指 | D♯6、A5、E5、A♯4、D♯4、A3 |
| 右食指 | A♯3、E4、A4、D♯5、A♯5、E6 |
| 左拇指 | C♯6、G5、D5、G♯4、C♯4、G3 |
| 右拇指 | G♯3、D4、G4、C♯5、G♯5、D6 |

一根手指預設控制一鍵，最多同時按兩個相鄰鍵。三個相鄰鍵的罕見指法暫不生成。例：G♯3＋G4 同屬右拇指，隔著 D4，必須拒絕。G♯3＋D4 雖符合按鍵鄰接規則，仍須通過獨立的音樂和聲檢查才可能出題。

## 顯示、播放與測驗

`GeneratedNote.chord` 儲存完整的同時發聲音高，包含原本旋律或低音；同一事件只佔一次時值。VexFlow 每個音都有符頭及必要臨時記號；播放逐音同時排程，換譜號或 8va/8vb 不改 MIDI。

收音評分仍為單音：琵琶／笙切到測驗模式時，顯示並評分原旋律；切回自由練習恢復和聲。鋼琴獨立雙手收音評分尚未支援。收藏儲存完整和聲；舊單音收藏可繼續開啟，不自動改寫。
