# 調性生成規則

所有樂器共用同一套調性抽選，不因高音笙或樂器音色固定成 C 或只使用降記號。

## 正常隨機練習

先抽調號類型，再抽符合該類型的音階與主音。未開啟「增加音高變化」時，升調號 35%、降調號 35%、C／無升降調號 25%、不使用調號的特殊音階 5%。開啟時沿用 35%／35%／10%／20%。這是每次抽選機率，不保證短期固定比例。

- 保留全部 33 種音階；音階選擇與主音控制仍隱藏。
- 一份樂譜內音階一致；鋼琴、揚琴雙手共享調性，兩個聲部音域都必須有候選音。
- 自訂音域限制導致某類型不可用時，只在剩餘可用類型重新分配機率。
- 優先使用易讀拼寫，避免重升重降；未開啟額外調外音時，初／中／進階優先選不超過 2／3／4 個升降號的調號。窄音域必要時保留可演奏的其他拼寫。
- 未開啟額外調外音時，主音候選會計算調號之外仍需多少升降音，優先使用最少的組合；同一調號類別內，也降低必需臨時記號較多的音階權重。全部音階仍可抽到，不靠刪音或省略必要記號來降低負擔。
- 例如 Pelog 五聲近似可抽 E–F–G–B–C，平調子可抽 A–B–C–E–F；兩者保留各自音程，同時不需滿頁臨時記號。使用固定主音的開發試奏仍按指定主音顯示必要記號。
- 日本、南洋近似、全音、減音階與非調性等原本不使用調號的音階，仍按音階定義逐音加臨時記號，不強加不合適的大小調調號。
- 額外調外音開啟時，初／中／進階機率分別為 4%／10%／18%。這項設定不刪除音階本身必需的升降記號。額外半音的拼寫依實際抽到的調號：升調號優先升音拼寫，降調號優先降音拼寫；C 或不使用調號時依旋律方向選擇。
- 音高難度、節奏、拍號、音域、和聲可演奏性及實音移調沿用原規則。鋼琴、揚琴左手仍使用音階內的和聲音。
- 已收藏樂譜維持原音符與原調性，開啟收藏不會重新抽選。
- 非調性與開啟額外調外音以外的新題，在抽好調性及節奏後，自動安排整份題目的調式走向、主音起訖與少量短旋律。詳細例外與限制見 [調式樂句規則](modal-phrasing.md)。

## 開發用音階試奏

`previewScale` 只固定第一份成功生成的譜，提供可見提醒與「回到隨機練習」連結。生成成功後移除網址參數，下一份恢復正常隨機與原本的額外調外音偏好。生成失敗可修正設定後重試；開啟收藏譜會結束試奏。正式建置忽略試奏參數。

## 驗證範圍

測試涵蓋所有樂器的四類調性、33 種音階可抽中、極窄自訂音域、雙手候選音、調外音拼寫、試奏退出與錯誤重試、收藏還原，以及 VexFlow 調號／臨時記號顯示與 Tone.js 播放回歸。
