# C 長線展開採用 B89

人類在 B88 三版比較後選擇「C 好些 就用C」。一般固定拍號練習現在使用已試聽的 C 長線展開；持續音入口、較長的旋律弧線、段落活動及收束都沿用 B88 的實作，沒有在採用時重新調整權重或換成 B。

採用邊界沿用 `supportsMusicalIntent`：一般音高／節奏練習、4 至 16 小節、五聲或七聲音階、固定拍號、不額外加變音。混合拍號、音階／跳進專項、指定節奏專項、其他音集合與舊版明確策略仍保留原路徑。七聲以音階內和弦支撐，五聲保留自己的音集合，不額外製造導音。沒有新增風格選單，也不重新生成已保存樂譜。

只改 `composeExercise` 的一般生成入口。`contrastStudy` 與 `contrastRhythm` 的演算法保持 B88，僅更新註解說明 C 已採用。原先 `composeIntentExercise` 仍可明確呼叫，以保留 B87 比較基準；原本專屬該作曲器的性格／起句測試改為測它的明確入口，一般流程的硬限制測試持續覆蓋新入口。

採用回歸測試保存四組試聽種子 `87001`、`87002`、`87003`、`87004` 的核心與完整後處理輸出雜湊，與 B88 已保存 C 樣本逐一完全一致。另保留 10 組不在採用範圍的修改前輸出及一組明確策略輸出，檢查沒有改變其亂數與結果。設定流程以獨立記憶體資料驗證會直接使用 C，既有譜面的恢復不重寫音高和節奏。

新增驗證種子事先指定為 `89017`、`89123`，用於實際樂器預設音域、支援的五聲／七聲音階、九種拍號及較短／較長篇幅的完整生成與後處理。檢查時值、記譜／播放一致、音域、調式、音高難度跳進、和弦音，以及播放事件的有限正時長。這些是規則檢查，不代替每個設定的人工試聽或實機驗收。

最終結果：880 項測試全部通過，建置與程式檢查通過。166 組前後完整生成案例包含 44 種可選樂器的 88 組音域案例、54 組調式案例、18 組拍號案例及 6 組篇幅案例。已出現的 37 個笙和弦、13 個琵琶和弦及輪音均通過對應指法／技法驗證；82 組雙手譜的指定外聲部平行／同向跳進完全音程診斷前後皆為零。這些計數只描述這一批樣本，不保證所有音樂內容皆符合完整嚴格對位。
