# 四分拍的八分三連音

2026-09-21：在一般出題的 2/4、3/4、4/4、5/4 節奏池加入八分三連音。每組三個八分音符佔一個四分音符拍，僅受節奏複雜度控制，與音高難度無關。

- 每拍選中三連音的權重比例：簡單約 4%、適中約 8%、複雜約 12%。保留其他節奏；不保證每份隨機短題一定含三連音。
- /8 拍號沿用原有二／三個八分音符群與十六分細分，不額外標成三連音。專項附點、十六分練習保持其重點。
- 事件以 `tuplet: 3` 標示；顯示時值為八分音符、實際時值為 `4/3` 個十六分單位。內部累加換算成整數 ticks，避免連續三分時值的浮點誤差。
- VexFlow 在建立 strict voice 前套用 3:2 ticks；連桿完整包住三音時只標 `3`，邊緣休止符或換譜號使連桿不完整時使用括號。數字跟隨整組符桿方向：朝上在連桿上方，朝下在連桿下方；數字靠近連桿，避開演奏記號。8va／8vb 在數字外側。
- 三連音內部分休止保留分組；整拍都休止則合併成四分休止符，整小節休止仍用整小節休止符。
- 播放、節拍器、拖曳游標與評分共用實際時間軸。收藏能存回三連音，並拒絕不完整組、不符拍號或顯示／播放時值不一致的資料。

回歸測試涵蓋三種音高難度、三種節奏級別、四種 /4 拍號、混合拍號、休止合併、真實 VexFlow ticks、連桿、游標、評分時間與收藏還原；原本 /8、和聲與大譜表測試繼續執行。
