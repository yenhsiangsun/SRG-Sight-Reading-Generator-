Tonecraft editorial font subsets

Tonecraft Display derives from Noto Serif TC.
https://github.com/google/fonts/tree/main/ofl/notoseriftc
Tonecraft Text derives from Noto Sans TC.
https://github.com/google/fonts/tree/main/ofl/notosanstc

Both are distributed under the SIL Open Font License 1.1.
Original copyright and full license text accompany each family.
Local variable WOFF2 subsets cover the application source text, weights400-700.
Unicode chunks load on demand; the first contains the opening page and shared text.
The internal names were changed to distinguish these subsets.
No endorsement by the upstream authors is claimed.
