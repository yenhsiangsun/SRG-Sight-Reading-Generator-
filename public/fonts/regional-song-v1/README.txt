Regional Song font subsets for Tonecraft

Tonecraft Song SC derives from Noto Serif SC; Tonecraft Song JP derives from Noto Serif JP.
https://github.com/google/fonts/tree/main/ofl/notoserifsc
https://github.com/google/fonts/tree/main/ofl/notoserifjp

SIL Open Font License1.1. Original copyright and licenses are retained beside the assets.
Locally renamed variable WOFF2 subsets cover application source text at native weights400-800.
Unicode chunks load only in the selected language; core chunks include the visible home text.
No external font requests are made at runtime. Characters outside application text may use system serif fallbacks.
